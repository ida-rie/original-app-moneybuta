# PWA テストチェックリスト

最終更新日: 2026-04-22

## 1. 共通（ブラウザ）

- `npm run build` が成功すること
- `/manifest.webmanifest` が 200 で返ること
- `/sw.js` が 200 で返ること
- 初回アクセス後に Service Worker が登録されること
- オフライン時に画面遷移で `/offline.html` が表示されること

## 2. Android（Chrome）

- アドレスバーのインストール導線が表示されること
- ホーム画面追加後、独立ウィンドウで起動すること
- タスク切り替えにアプリ名・アイコンが反映されること
- オフライン起動時にフォールバック画面へ遷移すること

## 3. iPhone（Safari）

- 「共有 > ホーム画面に追加」でインストールできること
- 追加後、Safari UI なしの standalone 表示で起動すること
- ホーム画面アイコンが `apple-touch-icon` で表示されること
- オフライン起動時にフォールバック画面へ遷移すること

## 4. 回帰観点

- サインイン後の通常導線（ホーム/クエスト/設定）が壊れていないこと
- API エラー時の既存トースト表示が維持されること
- SW 更新後に古いキャッシュが削除されること

## 5. Android インストール CTA

- Android Chrome でインストールバナーが表示されること
- 「インストール」押下でシステムダイアログが開くこと
- 「閉じる」で再表示抑制されること

## 6. iPhone 追加ガイド

- iOS Safari のみで案内モーダルが表示されること
- standalone 起動時には表示されないこと
- 閉じた後は再表示されないこと

## 7. Push 通知設定

- マイページの通知設定で有効化/無効化ができること
- `POST /api/push/subscription` で購読保存できること
- `DELETE /api/push/subscription` で購読解除できること
- `POST /api/push/test` でテスト通知送信できること（VAPID 設定時）
